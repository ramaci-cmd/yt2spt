Bagian 1 Penjelasan Sederhana • Pahami dalam 1 Menit

Bagaimana yt2sp Bekerja Tanpa Akun API Berbayar?

Aplikasi Spotify Desktop secara bawaan memiliki kemampuan untuk membaca daftar teks URI lagu langsung dari clipboard laptop Anda. yt2sp bertindak sebagai jembatan: mengambil daftar judul lagu dari playlist YouTube Anda, mencari versi resminya di Spotify, lalu menyalin kodenya. Anda cukup menekan tombol Ctrl + V di Spotify Desktop agar seluruh lagu masuk seketika. 100% gratis, aman, dan tanpa perlu login akun Spotify di web!

1

1. Masukkan Link & Ekstrak

Salin link playlist YouTube Music atau YouTube reguler, tempel di yt2sp, lalu klik "Mulai Ekstraksi Lagu". Sistem akan otomatis mencocokkan setiap lagu ke katalog Spotify.

2

2. Salin Blok URI Spotify

Di halaman Playlist atau Smart Genre Splitter, klik tombol hijau "Salin Semua URI Spotify". Semua kode lagu akan tersimpan otomatis di clipboard komputer Anda.

3

3. Buka Spotify & Ctrl + V

Buka aplikasi Spotify Desktop di komputer Anda, buat Playlist Baru, klik area daftar lagu, lalu tekan Ctrl + V (atau Cmd + V di Mac). Selesai!

Penting Diingat: Wajib menggunakan Spotify Desktop (aplikasi resmi Windows / Mac). Spotify versi Web Player di browser tidak dapat menerima paste URI karena batasan keamanan browser.
Bagian 2 Panduan Rinci & Mendalam • Alur Lengkap Dari A Sampai Z

Langkah Demi Langkah Menggunakan Seluruh Fitur yt2sp

Pelajari detail teknis setiap tahap proses transfer, fitur kurasi lagu di Review Studio, pembagian genre otomatis (Smart Genre Splitter), hingga trik penempelan Spotify Desktop tanpa error.

A

Tahap 1: Memasukkan Playlist & Ekstraksi Metadata

1. Masuk ke menu Transfer Playlist.

2. Masukkan link playlist YouTube Music (https://music.youtube.com/playlist?list=...), YouTube reguler (https://www.youtube.com/playlist?list=...), atau langsung ID playlist (PL...).

3. Fitur Batch Playlist: Anda dapat memasukkan lebih dari satu link sekaligus (pisahkan dengan baris baru). Sistem akan memproses seluruh playlist secara berurutan.

4. Klik tombol "Mulai Ekstraksi Lagu". Pantau status ekstraksi di bilah atas aplikasi.

B

Tahap 2: Kurasi Akurasi Lagu di Review Studio

1. Setelah ekstraksi selesai, buka playlist di tab Review & Kurasi.

2. Cek Match Score: Indikator warna menunjukkan akurasi pencocokan algoritma (Hijau = 100% cocok, Kuning = perlu dicek, Merah = judul berbeda).

3. Pilih Versi Alternatif: Jika lagu YouTube berupa cover, konser live, atau remix, klik tombol "Pilih Alternatif" untuk memilih rekaman studio asli dari daftar rekomendasi Spotify.

4. Input Manual: Jika ada lagu langka/indie yang belum ditemukan, klik ikon pensil untuk memasukkan link Spotify secara manual.

5. Pilih & Hapus (Batch Select): Gunakan kotak centang pada setiap lagu (atau tombol "Pilih Semua") untuk menghapus lagu yang tidak ingin dipindahkan via tombol merah "Hapus Terpilih".

C

Tahap 3: Pemisahan Genre Otomatis (Smart Genre Splitter)

1. yt2sp menganalisis artis dan track menggunakan kombinasi API Spotify dan MusicBrainz untuk mengklasifikasikan lagu ke genre masing-masing (Pop, Rock, Hip-Hop, R&B, Anime, Jazz, Electronic, dll).

2. Di panel Pemisah Genre, klik genre yang ingin Anda pisahkan. Anda dapat melihat daftar lagu yang termasuk dalam genre tersebut.

3. Klik tombol "Salin URI" pada genre tersebut untuk mengekspor lagu bergenre itu saja. Dengan trik ini, Anda bisa memecah 1 playlist YouTube besar menjadi beberapa playlist Spotify tematik!

D

Tahap 4: Trik Penempelan (Paste) di Spotify Desktop

1. Pastikan Anda membuka Aplikasi Resmi Spotify Desktop (Windows atau macOS), bukan versi browser (Web Player).

2. Buat playlist kosong baru dengan menekan tombol + (Buat Playlist) di panel kiri Spotify. Beri nama playlist tersebut.

3. (Trik Pancingan): Tambahkan 1 lagu sembarang ke playlist baru tersebut agar Spotify menginisialisasi tabel daftar lagunya.

4. KLIK PADA DAFTAR LAGU: Klik satu kali di atas baris lagu pancingan tersebut (atau area kosong tabel lagu). PERHATIAN: Jangan tekan Ctrl+V saat kursor Anda sedang aktif di dalam kotak pencarian (search bar) Spotify!

5. Tekan tombol Ctrl + V (di Windows) atau Cmd + V (di Mac). Seluruh lagu yang Anda salin dari yt2sp akan seketika masuk ke playlist! Lagu pancingan tadi kini bisa dihapus.

E

Tahap 5: Tips Tambahan & Pemecahan Masalah (Troubleshooting)

• Playlist Lebih dari 100 Lagu? Spotify Desktop membatasi penempelan maksimal sekitar 100 lagu per satu kali tekan Ctrl+V. Pada playlist besar, klik tombol "Salin per-Chunk 100 Lagu" untuk menyalinnya per bagian (Bagian 1, Bagian 2, dst.) lalu tempel bergantian.

• Mode Optimalisasi Laptop Kentang: Jika laptop Anda berspesifikasi rendah, aktifkan tombol "Kentang Mode" di pojok kanan atas atau sidebar. Fitur ini mematikan seluruh animasi dan efek blur sehingga antarmuka berjalan 100% ringan tanpa lag.

• Penyimpanan Database Lokal: Data lagu dan playlist Anda tersimpan secara lokal di database SQLite (yt2sp.db). Riwayat dapat dibuka kembali kapan saja tanpa perlu mengekstrak ulang dari YouTube.
